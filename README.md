# Imran Kabeer

Profile site for Imran Kabeer, B2B marketing leader for logistics and supply chain tech, Dubai.

Live at https://imrankabeer.com/

Static site: `index.html`, self hosted fonts in `fonts/`, portrait `imran.jpg`, share image `og.jpg`. Hosted on GitHub Pages from the `main` branch root. The custom domain is set in `CNAME`.

To edit: change `index.html` and push to `main`. GitHub Pages republishes in about a minute.
